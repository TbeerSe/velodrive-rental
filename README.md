# 🚲 ВелоДрайв — Одностраничный сервис проката велосипедов

Адаптивный фронтенд-проект современного сервиса аренды велосипедов. Включает в себя интерактивный каталог, динамический расчет стоимости поездки с учетом дополнительных опций, валидацию формы бронирования по дате/времени и кастомное модальное окно подтверждения. В подвале сайта интегрирована кастомная интерактивная карта станций проката.

Проект создан в рамках формирования личного портфолио для демонстрации навыков работы с чистым JavaScript (Vanilla JS), продвинутым CSS3 и внешними библиотеками.

## 🛠 Технологический стек

*   **HTML5:** Семантическая разметка, кастомные формы с валидацией типов данных, Aria-атрибуты для доступности интерфейса.
*   **CSS3:** Модульная структура, Flexbox, Grid Layout, CSS-переменные, адаптивные шрифты (`clamp`) и контейнеры (`min`), размытие фонов (`backdrop-filter`) для модальных окон.
*   **JavaScript (Vanilla JS):** Манипуляции с DOM, обработка событий (`input`, `change`, `submit`, `keydown`), форматирование дат и валюты через встроенные API, интеграция сторонней библиотеки по CDN.
*   **Leaflet.js:** Сторонняя библиотека для отрисовки интерактивных карт без тяжелых фреймворков.

## ✨ Ключевой функционал

*   **Умный инпут времени:** Разделение логики событий `input` и `change` позволяет пользователю комфортно редактировать количество часов вручную. Жесткая валидация диапазона (от 1 до 24 часов) срабатывает только при потере фокуса.
*   **Конструктор дополнительных опций:** Возможность добавить к аренде шлем или детское кресло. Итоговая сумма пересчитывается мгновенно на лету с использованием методов массивов (`.reduce()`).
*   **Валидация даты и времени:** Инпуты типа `datetime-local` предотвращают отправку пустых форм, а JS автоматически форматирует техническую строку ISO в красивую локальную дату (`ДД.ММ.ГГГГ, ЧЧ:ММ`) для вывода пользователю.
*   **Кастомное модальное окно:** Полностью заменяет устаревший браузерный `alert()`. Реализовано закрытие по клику на оверлей, крестик или нажатием клавиши `Escape`. Блокирует прокрутку страницы (`overflow: hidden`) при открытии.
*   **Интерактивная карта станций:** Внедрена полноценная карта города на базе Leaflet.js с использованием стильной темной подложки `CARTO Dark Matter`. На карту нанесены маркеры станций проката с кастомными всплывающими балунами (попапами), стилизованными под дизайн сайта.
*   **Полная адаптивность:** Сетка сайта и все элементы управления оптимизированы под мобильные устройства (до 320px).

## 📂 Структура проекта

*   `index.html` — семантическая разметка страницы, форм и модального окна.
*   `style.css` — стили, переменные, кастомные темы для карты и адаптивные медиа-запросы.
*   `script.js` — логика калькулятора, валидация, управление модальным окном и инициализация карты.
