# ВелоДрайв — прокат велосипедов

Одностраничный сайт сервиса по аренде велосипедов: адаптивная вёрстка, интерактивные карточки с расчётом стоимости, модальное окно подтверждения и карта станций на Leaflet.

**Демо:** https://tbeerse.github.io/velodrive-rental/

## Стек

- HTML5 (семантика, ARIA)
- CSS3 (Grid, Flexbox, переменные)
- Vanilla JS (ES-модули)
- Leaflet + тайлы CARTO Dark Matter
- Google Fonts (Inter)

## Структура

    VeloDrive/
    ├── index.html
    ├── css/   (7 файлов)
    ├── js/    (4 файла)
    └── README.md

## Запуск

Открой index.html в браузере. Для ES-модулей удобнее локальный сервер:

    python3 -m http.server 8000
